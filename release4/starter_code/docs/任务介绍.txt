任务介绍

现在我们的主线已经从单 VM 换成了多 VM / CVM。

之前最好的单 VM 分数是 62.5085。现在多 VM 已经到：

CD 58.6531
P2S 78.6321
final 68.6426

当前最好权重是：
/root/autodl-tmp/experiments/straightpcf_cvm_cache12000_ep29_ft30_lr5e5/checkpoint_29.pkl

我们现在的问题是：
模型很会把点拉近表面，所以 P2S 很高；但 CD 还不够高，说明点云覆盖和局部分布还可以继续优化。

接下来不建议你继续在单 VM 后面做 CDRefine。更值得做的是：在多 VM 训练里直接加一点“分布约束”，让主干模型训练时就同时照顾 P2S 和 CD。

你要做的事：

1. 基于当前多 VM 新建一个模型，不要改坏原来的 CVM。
2. 保留原来的 CVM loss。
3. 额外加小权重 Chamfer loss，让输出更像 clean patch。
4. 加小权重 residual anchor，防止点移动太猛。
5. 先不要加很强的过密惩罚，等 Chamfer 版有效后再说。

训练方式：

从当前最好 CVM 继续训，不要从头训。
先训 5 或 10 epoch。
训练数据用已有 patch cache。

看结果时主要看：

CD 有没有涨
P2S 有没有大掉
final 有没有超过 68.6426

如果 CD 涨、P2S 基本不掉，就继续。
如果 P2S 掉很多，说明分布约束太强，需要降权重。

简单说：
不要等模型先把点云分布压坏，再靠第二阶段补 CD。现在要试的是让多 VM 主干本身就学会“贴表面但不破坏分布”。
