给队友看的精简版

我们现在最强的不是单 VM，而是多 VM / CVM。

分支：
exp/surface-straight-vm

模型：
StraightPCFCoupledVelocityModule

最好权重：
/root/autodl-tmp/experiments/straightpcf_cvm_cache12000_ep29_ft30_lr5e5/checkpoint_29.pkl

当前分数：
CD 58.6531
P2S 78.6321
final 68.6426

建议你别继续在单 VM 后面做 CDRefine。更好的方向是：直接在多 VM 训练里加“分布约束”，让模型靠近表面的同时别破坏 clean 点云覆盖。

新实验目标：

原 CVM loss
+ 小权重 Chamfer(output, clean_patch)
+ 小权重 residual anchor
+ 后续再考虑 density matching

先别一上来加很强的过密惩罚，容易把边缘和薄结构抹平。

训练方式：

从当前最好 CVM 继续训，不要从头训。

用 patch cache：
/root/autodl-tmp/cache_surface_straight_nf12000_seed123

稳定配置：
batch_size=2
num_workers=0
lr=2e-5
先训 5 或 10 epoch

看三个指标：
Mean CD score
Mean P2S score
Mean final score

判断：

CD 涨，P2S 基本不掉，就继续。
CD 涨但 P2S 小掉，也可以继续。
P2S 大掉且 final 不涨，说明分布 loss 太强。

一句话：
不要等第一阶段把分布压坏后再补 CD，而是让多 VM 主干训练时就同时照顾 surface 和 clean patch 分布。
