任务目标：
不要继续在单 VM 后面硬接 CDRefine。请在多 VM / CVM 训练里加入小权重分布约束，让模型一边贴近 surface，一边保持 clean patch 覆盖。

建议新建模型，不要破坏原 CVM：

src/model/straightpcf_cvm_distribution.py
class StraightPCFCoupledVelocityDistributionModule

并在 src/model/parse.py 注册。

loss 思路：

loss = 原 CVM loss
     + chamfer_weight * Chamfer(pc_pred, pc_clean)
     + residual_weight * ||pc_pred - pc_current||^2
     + 可选 density_weight * density_matching(pc_pred, pc_clean)

先只做最小版：

原 CVM loss + 小权重 Chamfer + 小权重 residual_anchor

先不要加很强的 density loss，容易把边缘和薄结构抹平。Chamfer/density 为省显存只随机采样 256 点算。

推荐初始超参：

num_dist_points: 256
chamfer_weight: 0.2
residual_weight: 0.01
density_weight: 0.0
lr: 0.00002
batch_size: 2
num_workers: 0

/root/autodl-tmp/experiments/straightpcf_cvm_cache12000_ep29_ft30_lr5e5/checkpoint_29.pkl

第一轮只跑 5 或 10 epoch。看 CD/P2S/final，不只看 loss。

判断标准：

CD 涨，P2S 掉不到 1：继续
CD 涨 2 左右，P2S 掉 1-2：仍可继续
P2S 掉超过 3 且 final 不涨：loss 太激进，降权重或降 lr
CD 和 P2S 都涨：继续 10 epoch
