任务：
新建一个多 VM 加分布约束的模型，不要破坏原模型。

建议文件：
src/model/straightpcf_cvm_distribution.py

建议类名：
StraightPCFCoupledVelocityDistributionModule

并在 src/model/parse.py 注册。

核心目标：
保留原 CVM loss，同时加入小权重分布约束，让输出既靠近 surface，也更像 clean patch 的覆盖分布。

先做最小版 loss：
loss = 原 CVM loss
     + chamfer_weight * Chamfer(pc_pred, pc_clean)
     + residual_weight * ||pc_pred - pc_current||^2

先不要加强 density loss。过强的过密惩罚容易抹平边缘和薄结构。

初始建议：
num_dist_points: 256
chamfer_weight: 0.2
residual_weight: 0.01
density_weight: 0.0
lr: 2e-5
batch_size: 2
num_workers: 0

训练从当前最好 CVM 继续，不要从头训：
/root/autodl-tmp/experiments/straightpcf_cvm_cache12000_ep29_ft30_lr5e5/checkpoint_29.pkl

训练用 patch cache：
/root/autodl-tmp/cache_surface_straight_nf12000_seed123

cache 里必须有：
pc_noisy, pc_clean, pc_mix, pc_time

先训 5 或 10 epoch，然后测：
Mean CD score
Mean P2S score
Mean final score

判断：
CD 涨且 P2S 基本不掉，可以继续。
CD 涨但 P2S 小掉，也可以继续。
P2S 大掉且 final 不涨，说明分布 loss 太强，要降权重或降 lr。

不要做：
1. 回到单 VM 当主线
2. 从头训练
3. 提交临时 YAML
4. 只看 loss 不测分
5. 一开始就上大 density loss
